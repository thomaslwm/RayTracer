# RayTracer

## Introduction
This project aims to implement the raytracer detailed in the [Ray Tracing in One Weekend](https://raytracing.github.io/books/RayTracingInOneWeekend.html) e-book. It is currently a work in progress, and contains no features that are not already detailed in the e-book. I aim to expand this to include rendering of other materials, and shapes other than the basic spheres that are included in the book.

## Features

### Currently implemented:

- Mutable list of hittable objects
- Sphere hittable calculations
- Normal shading
- Image output

### Future features:

- Reflectivity for materials
- Animations
- Saving scene description files
- Diffuse lighting
- Customizable image output
